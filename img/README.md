# Imágenes del grupo

Coloca aquí las fotos reales. Mientras no existan, la landing usa
placeholders automáticos (no se rompe nada).

Nombres que la landing busca:

- `hero.jpg` — imagen de fondo del hero (recomendado ~1920×1080)
- `historia.jpg` — foto para la sección Historia (~640×480, 4:3)
- `galeria-1.jpg` … `galeria-6.jpg` — galería (vertical, 4:5)
- `og-cover.jpg` — imagen para compartir en redes (~1200×630)

Formatos recomendados: `.jpg` o `.webp` optimizados para web.
